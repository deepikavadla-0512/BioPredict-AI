# BioPredict AI

BioPredict AI is an AI-powered platform for biological prediction, genetic analysis, and computational research.

The platform provides multiple machine-learning-based models for exploring biological and genetic data.

## Features

- SARS-CoV-2 classification and mutation pattern prediction
- MECP2 SNV pathogenicity classification
- Viral disease prediction
- Splice site prediction
- Drug-target pair analysis
- Future support for additional biological prediction models

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Machine Learning
- Computational Biology
